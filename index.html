Поиск в интернете

Подключение через SerpAPI

Не подключён

Сайт отправляет запросы к поисковому API и показывает публичные страницы с заголовком, ссылкой и описанием. Не используем скрытый сбор данных из закрытых аккаунтов.

Как включить реальный поиск
  1. Создай ключ на serpapi.com.
  2. Открой файл .env в папке проекта.
  3. Добавь строку SERPAPI_KEY=твой_ключ и перезапусти сервер.
ⓘ

Без ключа поиск работает в демо-режиме на примерах. Демо-результаты помечены и не являются реальными заявками.
