# Video Client Finder — разделённая версия

Файлы:
- `index.html` — структура сайта
- `style.css` — стили и адаптивная вёрстка
- `script.js` — логика поиска, базы клиентов, CSV и шаблонов сообщений

## Запуск
Оставьте все три файла в одной папке и откройте `index.html` в браузере.
Для локального веб-сервера можно выполнить `python -m http.server 8000`, затем открыть http://localhost:8000.

Данные сохраняются в localStorage текущего браузера. Автоматический парсинг поисковых результатов не подключён.
