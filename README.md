# ClipFinder

Минималистичный SaaS-интерфейс для поиска потенциальных клиентов для видеомонтажёра.

## Структура

- `index.html` — разметка интерфейса
- `styles.css` — весь дизайн и тёмная/светлая тема
- `app.js` — интерактивность, поиск, сохранение, CSV и переключение темы
- `server.js` — сервер и API-посредник для поискового API
- `package.json` — зависимости и команды запуска
- `.env.example` — пример переменных окружения

Фронтенд разделён на **HTML + CSS + JavaScript**. Серверные файлы оставлены отдельно, потому что реальный поиск через API нельзя безопасно выполнять только из браузера.

## Тема

По умолчанию включена тёмная тема. Кнопка с солнцем/луной в верхней панели переключает тему и запоминает выбор в браузере.

## Запуск

```bash
npm install
npm start
```

Затем открой `http://localhost:3000`.

Для реального поиска создай `.env` и добавь:

```env
SERPAPI_KEY=твой_ключ
```

Без ключа сайт работает в демо-режиме и явно помечает демонстрационные результаты.
